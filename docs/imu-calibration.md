# IMU 校准流程与算法说明

本文说明当前 BMI088 六轴姿态功能的校准方法、使用步骤和限制，是长期维护的功能说明，**不是某次烧录或实板验收报告**。软件回归通过、CRC 正常或界面出现有效姿态，都不等于实板轴向及角度精度已经验收通过。

## 1. 当前采用什么方法

采用以下流程：

> 连续静置检测 → 陀螺零偏均值估计 → 用重力初始化 roll/pitch、将 yaw 置零 → 六轴 Mahony 四元数融合。

当前“校准”可由上电、采样异常导致的融合重置，或上位机手动命令触发；随后自动等待静置并初始化，不是完整的传感器工厂标定：

- 估计本次静置条件下的三轴陀螺零偏，并在后续姿态积分中扣除。
- 根据静置加速度均值确定初始倾角，不要求桌面绝对水平。
- 不校准加速度计零偏、比例因子、轴间不正交误差，也不做六面加速度计参数拟合。
- **未接入 BMM150 或其他磁力计**，不包含磁罗盘硬铁/软铁标定；yaw 是允许漂移的相对航向，不是磁北或真北。

## 2. 实际使用步骤

1. **稳定放置板卡。** 使用稳定支撑，避免手持、桌面振动和 USB 线缆拉扯。板卡可以带固定倾角，不必刻意把 roll/pitch 调到零。
2. **上电后保持静止。** 有效样本先建立约 200 ms 的统计窗口，再连续满足约 2 s 静置条件。理想连续 1 kHz 输入下约需 **2.2 s**；这是算法时序估计，不是任意实板都能保证的完成时间。
3. **观察上位机姿态状态。** “校准中（请静置）”时不使用角度；变为“有效 · 相对航向”后，才将当前姿态作为有效输出。原始六轴可独立显示，不代表姿态已经初始化。
4. **校准完成后再转动。** 此时使用扣除零偏的陀螺跟踪姿态，并在加速度适合时进行重力修正。正常转动不需要一直满足静置判据。
5. **需要重新初始化时，点击上位机“重新校准 IMU”并确认，再保持静置。** 无需复位或重新上电；也可通过复位或重新上电重新初始化。正常 USB 断开重连不会清零姿态或 yaw。真实采样异常触发融合重置时，也需重新静置。

校准期间移动导致判据不满足，会清除已累计的静置时间和均值，重新等待连续合格区间。不要靠反复插拔 USB 来代替稳定放置。

### 2.1 从上位机手动重新校准

1. 保持 IMU 连接且已有数据，将板卡放稳；按钮是否就绪依据 IMU，不要求相机先交付图像。
2. 点击 **重新校准 IMU**，阅读相对 yaw 将归零的提醒后确认。确认框默认选择“否”，取消不会发命令；确认后不重启 MCU，也不停止原始六轴采集或当前录制。
3. **“已发送，等待板端执行确认”不等于已执行；“板端已执行”也不等于校准完成。** 收到 ACK 后，继续静置；理想连续输入约 2.2 s 后恢复有效姿态，运动则延迟完成。上位机仅接受不早于 ACK 重置时间边界的有效样本为完成依据，旧积压有效帧不能提前完成本次操作。
4. 操作等待期间，实时姿态数值显示破折号、趋势断开；旧历史保留，原始六轴和线上传感器 CSV 不被遮蔽状态改写。真实校准无效帧的姿态 CSV 仍留空。新校准完成后的 yaw 使用新零点，不能直接与操作前航向拼接。
5. 等待执行确认超过 **3 s** 时显示“结果未知”，可能是旧固件不支持、链路或执行异常；不会自动重发，仍接受匹配的迟到 ACK。先检查固件和连接，不要把超时理解成确定未执行。收到 ACK 后超过 **30 s** 仍未有效会提示继续静置，不反复自动重置。

录制的 `usb.bin` 保留执行 ACK，`events.jsonl` 保存请求生命周期、实际重置边界及新 yaw 参考首次有效时间；`session.json` 记载该语义。开始录制时还记录当前手动校准状态，便于区分录制开始前已发起的操作。USB 断开会终止当前控制会话，不自动补发请求；重连本身不归零。校准参数仅驻留 RAM，不写入 Flash，掉电后不会沿用本次零偏。

## 3. 静置是如何判定的

融合按固定 **1 kHz** 网格处理样本，使用 **200 个样本（约 200 ms）** 的滑动窗口。输入首先须通过源时效和 SPI 质量检查；窗口填满后，以下条件必须同时满足：

| 判据 | 当前门限 | 数据来源 |
| --- | --- | --- |
| 当前角速度向量模长 | 小于 5 °/s | 未经检测低通的三轴陀螺 |
| 当前加速度模长距 1 g 的偏差 | 不超过 0.1 g | 原始加速度 |
| 窗口内加速度各轴标准差 | 各轴不超过 0.02 g | 原始加速度 |
| 窗口内角速度各轴标准差 | 各轴不超过 0.5 °/s | 30 Hz 检测专用低通后的陀螺 |

连续合格时间达到 **2,000,000 μs** 才完成校准。普通运动只清连续静置累计，保留检测滤波器和滑动窗口；坏样本、过期样本、重复/回退的陀螺源时间或不连续的 1000 μs 节拍会清除检测历史，重新建立窗口。

这些门限是当前固定参数，并非对任意振动环境都可靠。特别是：**阈值内的恒定慢速 yaw 转动可能无法与陀螺零偏区分**，因此仍需用户真实静置，不能把“判静通过”理解为“任何运动均被排除”。

### 3.1 为什么加入 30 Hz 低通

针对陀螺高频波动导致静置标准差超限的问题，静置检测器对每轴采用一阶低通：

~~~text
y[k] = y[k-1] + α × (x[k] - y[k-1])
α = 1 - exp(-2π × 30 / 1000) ≈ 0.1717958187
~~~

首个合格样本直接初始化滤波状态；节拍中断等异常后重建状态，而非改变滤波带宽。

**该低通只用于静置判据中的陀螺窗口标准差：**

- 不改变 USB 原始六轴数据。
- 不用于零偏均值累计，也不用于姿态角速度积分。
- 不滤波加速度，不改变加速度重力修正门控。
- 当前未滤波角速度模长仍须小于 5 °/s，不能仅凭滤波后平稳就接受明显转动。

低通能减少高频波动对判静的影响，但**不能据此证明波动来源一定是测量噪声，而不是机械振动或电气干扰**。

## 4. 零偏与初始姿态如何计算

### 4.1 单位与安装旋转

固件内部先换算为 g 和 °/s：

~~~text
a[g]   = raw_accel × 24 / 32768
ω[°/s] = raw_gyro  × 2000 / 32768
~~~

融合输入沿用历史 ROTATION_PITCH_180，即 X、Z 取反：

~~~text
(x, y, z) → (-x, y, -z)
~~~

该旋转独立配置于 [fusion.h](../firmware/include/fusion.h) 的 FUSION_INSTALLATION_PITCH_180，默认启用。**原始六轴输出仍保持芯片寄存器轴和原有单位，不旋转、不扣零偏，也不套用静置检测低通。**

本项目按历史配置使用该安装旋转，但历史配置和原理图都不能证明实板方向。六面静置及绕已知机体轴转动用于核验轴向，不等于本功能已实现六面加速度计标定；发现不符应修正融合安装旋转并重测，不得修改原始输出轴定义来迁就角度。

### 4.2 陀螺零偏均值估计

连续合格静置期间，累计**已应用安装旋转、但未经检测低通**的六轴样本。对各轴陀螺求均值：

~~~text
bias[i] = mean(ω[i]) × π / 180          // 内部保存为 rad/s
ω_corrected[i] = ω_measured[i] × π / 180 - bias[i]
~~~

静置时真实角速度应接近零，因此将这段均值作为本次零偏。后续融合扣除该偏置，而不是把偏置写回原始数据。

当前只在初始化时估计一次；正常运行不持续重估零偏。温漂和慢变偏置仍可能造成误差，尤其会积累为 yaw 漂移。

### 4.3 用重力初始化 roll/pitch

设静置加速度均值 āx、āy、āz 已应用安装旋转。加速度计测量的是比力，静置时方向与重力相反，因此实现使用：

~~~text
roll  = atan2(-āy, -āz)
pitch = atan2(āx, sqrt(āy² + āz²))
yaw   = 0
~~~

以上角度计算使用弧度。初始四元数按 yaw = 0 构造：

~~~text
cr = cos(roll/2),  sr = sin(roll/2)
cp = cos(pitch/2), sp = sin(pitch/2)
(qw, qx, qy, qz) = (cr×cp, sr×cp, cr×sp, -sr×sp)
~~~

校准成功不意味着 roll/pitch 都是 0°：若板卡本身倾斜，输出应反映倾斜。yaw 置零只是选择本次初始化的相对航向起点，并没有测出北向。

## 5. 校准后如何持续解算

融合采用六轴 Mahony，固定增益 **Kp = 2 s⁻¹、Ki = 0**：

- 用扣零偏后的陀螺积分四元数，每步归一化。
- 仅当加速度有效、模长接近 1 g，且原始加速度窗口各轴波动合格时，利用测得方向与预测重力方向的误差作比例修正。
- 加速度不适合重力修正时，暂时只积分合格陀螺；运行时不要求陀螺满足静置标准差，才能跟踪转动。
- 无磁力计，重力不能提供绕竖直方向的绝对参考，因而不能长期消除 yaw 漂移。Ki = 0 也意味着当前不通过积分反馈持续学习偏置。

输出采用机体 **FRD（前、右、下）**、世界 **NED（北、东、下）** 约定；由于没有北向观测，水平航向实际是本次校准定义的相对方向。四元数顺序为 qw、qx、qy、qz，表示机体到世界的旋转；Euler 为 3-2-1 顺序，输出单位为度。pitch 接近 ±90° 时 Euler 有奇异性，应优先使用四元数。

## 6. 无效、重校准与 USB 重连

| 情况 | 当前行为 |
| --- | --- |
| 陀螺年龄超过 1000 μs、年龄大于共同时间戳、SPI 错误，或源时间重复/回退 | 不积分该陀螺，当前帧姿态无效，清检测历史；短暂异常不一定整体重校准 |
| 加速度过期或 SPI 错误 | 清检测历史；未初始化时不能完成静置校准，已初始化时可仅积分合格陀螺 |
| 非连续但间隔不超过 10 ms 的节拍 | 清检测历史，不追补缺失段，仅积分当前至多 1 ms |
| 共同时间戳不递增、样本间隔超过 10 ms，或距上次合格陀螺超过 10 ms | 融合重置，重新静置校准 |
| 主循环发现超过 10 ms 没有新融合样本 | 融合重置，重新静置校准 |
| 融合快照队列溢出 | 废弃积压并重置融合，重新校准；保留丢失诊断和序号缺口 |
| USB 背压造成发送队列丢帧 | 报告发送丢失，不因发送丢失本身重置融合 |
| 正常 USB 断开、关闭、挂起及重连 | 融合继续更新，仅重建发送会话，不重置姿态或 yaw |
| 上位机确认手动重校准 | 在命令之后的新融合样本处重置，ACK 报告执行边界；等待连续静置，完成后 yaw 使用新零点；原始采样和录制继续 |
| MCU 复位或断电重启 | 重新校准，完成后 yaw 再次归零 |

IMU2 v3 的状态位为：bit 10 校准中、bit 11 当前帧姿态有效、bit 12 融合重置事件。**只有 bit 11 置位且校准/重置位未置位，才可接受为有效姿态**；上位机还检查数据质量、有限数值和四元数归一化等条件。不要仅依赖一次重置事件，因为 USB 关闭或丢帧期间可能漏收该事件。

板端校准或姿态无效时，GUI 角度显示破折号、趋势断开，CSV 姿态数值留空；手动请求等待确认期间只额外遮蔽实时显示，不改写已接收的真实传感器 CSV；旧 v2 帧也没有有效姿态。原六轴继续按各自质量标志判断。CRC 和序号正常只说明部分传输质量正常，不能证明校准、静置或角度精度合格。

## 7. 如果一直停在“校准中”

建议按以下顺序排查，而不是先盲目放宽门限：

1. 检查稳定支撑、线缆拉力、风扇/电机/桌面振动，确认没有在缓慢转动。
2. 检查陀螺与加速度源年龄、SPI 错误、节拍连续性及融合队列丢失，排除检测窗口反复重建。
3. 检查当前原始角速度模长、加速度模长，以及窗口内原始加速度和检测低通后陀螺的各轴标准差，确定具体未通过的判据。
4. 如需分析噪声或振动，可使用采集数据的频谱和回放，比较固定方式或环境变化；低通后变平稳并不能单独判定噪声来源。
5. 更改门限或滤波参数后，重新测试静置能通过、运动不误触发，特别关注缓慢转动场景。软件回放不能代替实板轴向和已知角度验收。
