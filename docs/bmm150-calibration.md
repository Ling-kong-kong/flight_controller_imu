# BMM150 离线硬铁/软铁候选标定

## 范围和当前边界

本工具在主机端拟合磁场椭球，产出**候选参数**。不打开串口、不下发参数、不修改固件，不启用磁融合，也不改变现有六轴 yaw。采集接口和协议见 [通信与磁场采集指南](bmm150-validation.md)。原始磁场始终保留 BMM150 芯片寄存器轴和工厂 trim 补偿后的 µT，不覆盖原始文件。

目标“开机 yaw 归零并抑制漂移”不能仅凭椭球拟合验收。当前固件已实现默认开启的实验性门控/航向辅助，见 [磁门控与相对 yaw 融合](bmm150-fusion.md)；独立磁轴、倾斜补偿和动态抑漂的完整实板验收仍须完成。相对 yaw 的零点应来自启动时的有效参考，不等于磁北或真北。

本文是可复用操作说明，不包含特定实板验收结论。原始数据、每轮拟合候选 JSON、分析、日志、验收报告均存入已忽略的 `logs/bmm150/`，不提交。经选择保留的数值成果另存为 [集成候选配置](../config/bmm150-calibration-candidate.json)，它不是运行时加载配置；当前固件将其中的数值固化在 mag_calibration.h，GUI 不加载该文件。

候选配置保留芯片轴偏置、对称软铁矩阵、拟合参考模长与来源候选 SHA-256；不包含采集数据或验收报告。JSON 保留候选选择当时的历史边界，`status=candidate_only`，安装旋转为空，`mounting_rotation_verified`、`firmware_applied`、`magnetic_heading_fused` 均为 false。保留数值不代表所有姿态/局部磁场检查通过，不能仅修改这些字段来启用融合。

## 1. 安装依赖与准备

```powershell
python -m pip install -r tools/requirements.txt
python -m pip install -r tools/requirements-mag-calibration.txt
```

采集依赖 pyserial；离线标定额外依赖 NumPy，基础采集不强制安装 NumPy。

- 使用最终传感器安装状态，保持打印件、板上配件和供电方式一致。配件或安装改变后需重测。
- 远离磁铁、扬声器、钢桌、大电流线等。肉眼未见干扰不代表局部磁场恒定。
- 裸板和线缆必须安全固定，避免拉扯连接器、短路和强拉线缆。不能安全翻转时不要勉强执行。
- 关闭其他串口读者。端口用实际枚举值替换示例 `COM12`，每轮使用新的本地目录。

## 2. 全方向采集及原始回放

```powershell
New-Item -ItemType Directory -Force logs/bmm150/calibration-run
python tools/mag_capture.py --port COM12 --seconds 120 --raw logs/bmm150/calibration-run/usb.bin --csv logs/bmm150/calibration-run/mag.csv --summary logs/bmm150/calibration-run/summary.json
python tools/mag_capture.py --input logs/bmm150/calibration-run/usb.bin --csv logs/bmm150/calibration-run/replay.csv --summary logs/bmm150/calibration-run/replay.json
```

采集期间缓慢、连续地绕三个轴转动，覆盖六面和斜向，避免只在桌面上水平绕圈；不要快速甩动或拉紧 USB 线。不需要面向地理北向，不按时间插值或补造丢失样本。

检查：

1. 磁场 valid/trim/config 正常、总线和补偿错误不增长，三轴均覆盖正负方向。
2. 同时检查 IMU 1 kHz、源时效、CRC、序号和融合队列诊断。磁帧序号缺口及 `tx_overwrites` 必须保留，不能被拟合掩盖；`not_ready` 正常增长不是丢帧。
3. 磁时间戳是寄存器读取完成时间，不是转换时刻。统计的连续序号周期最大值不包含跨序号缺口的间隔，需另查实际相邻接收间隔。
4. 同一原始文件重解后的磁 CSV 应逐字节相同，统计应相同。

## 3. 离线拟合候选

```powershell
python tools/mag_calibrate.py --input logs/bmm150/calibration-run/mag.csv --output logs/bmm150/calibration-run/candidate.json
```

输入要求：有效样本不少于 500、不超过 50000，含 `valid,x_ut,y_ut,z_ut,timestamp_us`；有效时间戳须严格递增且属于同一次采集。无效行只计数并跳过；有效行出现非有限数、非法时间戳、退回或重复时间戳则报错。不要把重连、重启或重复回放的数据直接拼接为一轮标定。

方法：

- 对三轴均值/尺度归一化，使用 9 参数线性最小二乘拟合椭球。
- 从二次型求中心作为硬铁偏置 `bias_ut`，对正定二次型取对称平方根得到软铁修正。
- 列向量公式：`corrected = M @ (measured - bias)`。`M` 为对称正定矩阵，并归一化为 `det(M)=1`。
- 该归一化保持体积尺度，**不能确定真实绝对地磁强度**；拟合参考模长不等于外部测量真值。
- 不自动删除离群点，以免隐藏磁干扰或模型失配。
- 仅靠模长不能识别坐标旋转/轴符号，不能证明磁轴映射或航向精度。

首版候选门限为工程防护，不是 BMM150 精度规格：

| 项目 | 门限 |
|---|---|
| 设计矩阵 | 满秩 9，条件数 ≤10000 |
| 修正方向的六面支持 | 每个正/负轴至少达到 0.75 |
| 方向二阶矩最小特征值 | ≥0.10 |
| 空间方向覆盖 | 26 个方向 bin 中至少 18 个各有 ≥3 点 |
| 修正模长变异系数 | ≤5% |
| 相对拟合参考模长的绝对残差 P95 | ≤10% |
| 软铁修正条件数 | ≤5 |

退出码：`0` 候选通过；`2` 拟合成功但候选门限未通过（仍写 JSON）；`1` 输入、拟合或文件错误（无可用的新候选）。参数错误由 argparse 返回 `2`。执行失败时不要误用上一次遗留 JSON。

JSON 记录输入文件 SHA-256、有效数和跨度、偏置/矩阵、覆盖和残差。即使 `candidate_accepted=true`，`independently_validated`、`mounting_rotation_verified`、`firmware_applied`、`magnetic_heading_fused` 仍为 false；它们是边界声明，不可手改为 true 冒充验证。

## 4. 固定候选的独立验证

**不要重新拟合验证集，也不要仅凭训练集残差宣布成功。** 同次采集的分段/留出分析可发现不稳定性，但不替代独立采集。

1. 保持相同安装和供电，固定上一轮的偏置与矩阵，另存一轮原始数据。
2. 明确标记静置段和全方向转动段；检查不同姿态静置的均值、标准差，以及转动时修正模长 CV/P95。不能假定采集尾段就是静置。
3. 对验证集逐点应用固定 `M` 和 `bias`；残差以原候选 `reference_norm_ut` 计算，不用验证集重新定中心、缩放或拟合。辅助调用：

```python
import json
import numpy as np
from tools.mag_calibrate import read_csv, apply, norm_stats

with open('logs/bmm150/calibration-run/candidate.json', encoding='utf-8') as f:
    candidate = json.load(f)
values, source = read_csv('logs/bmm150/independent-run/mag.csv')
corrected = apply(values, candidate)
print(source, norm_stats(corrected))
print('relative residual P95:', np.quantile(
    np.abs(np.linalg.norm(corrected, axis=1) / candidate['reference_norm_ut'] - 1), .95))
```

4. 至少复查上述模长残差门限，逐段检查异常；覆盖、传输诊断和磁场随时间变化也要单独判断，不以全局平均掩盖后段恶化。
5. 六面及已知方向转动核验磁轴到机体 FRD 的旋转，不能照抄历史 `ROTATION_YAW_180` 当作已核验。IMU 继续使用自己的历史安装旋转，原始两类轴定义均不改动。
6. 模长通过仍不等于航向精度通过；后续需检查倾斜补偿、绕轴角度符号、回到原方向的重复性，以及开机相对归零。世界水平磁分量过小、重力质量不可信、磁干扰、过期/丢帧时应停止磁修正，避免拉偏 yaw；使用四元数投影后不因机体倾角大本身拒绝。

发现残差后段升高时，应区分噪声、时变/局部磁场、方向相关模型误差与采集时序问题，保留证据再设计控制变量复测，不能未经验证就归因为“测量噪声”。

## 5. 集成与验收顺序

当前软件已实现实验性融合并默认开启，但不等于以下阶段已完整实板验收。必须按以下顺序核验，上一阶段未通过不得把下一阶段视为已验收：

| 阶段 | 工作 | 通过条件 |
|---|---|---|
| 磁轴对应核验 | 独立安装旋转，先离线筛选，再已知方向三轴实测 | 固定映射在各轴正/反向和多姿态下都与 IMU 一致；不能仅凭历史配置或模长 |
| 异常磁场/时效门控 | 拒绝、退回六轴、恢复滞回及诊断 | 坏场、过期、重复、丢失等回归通过；坏观测不改变 yaw 参考 |
| 倾斜补偿与抑漂 | 先离线比较，再受控启用与实板验收 | 回到同方向可重复，倾斜不引入显著伪航向，漂移改善且坏场不拉偏 |

### 5.1 磁轴到 IMU 的对应关系

处理顺序为 `m_frd = R_mag_to_frd @ M @ (m_chip - bias)`：先在 BMM150 芯片轴减偏置、软铁修正，再用独立右手安装旋转转换至 FRD。`M` 与 `R` 不可交换；IMU 自己的 `ROTATION_PITCH_180` 不自动适用于磁场。原始磁帧和六轴输出均保持原轴定义。

离线初筛可枚举 24 个行列式为 +1 的带符号轴排列，检查 `Q_body_to_world(t) @ m_frd(t)` 在短时转动中的方向一致性。使用未融合磁场的六轴姿态、固定候选，不重拟合、不按结果剔除磁异常；明确选段规则、运动激励、相邻区间重叠和姿态/磁场时间匹配。分别报告零时间偏移及偏移敏感性，跨独立数据集和分段复核。磁帧时间戳为读取完成时间，偏移最优值不能直接当作转换延迟。此方法假设短时局部磁场稳定且安装轴对齐；若所有排列都不一致，不能强选“最小残差”，需排查时序、场变化或非轴对齐安装。

实板定向核验：

1. 安全固定传感器与线缆，标清沿用的 FRD：前 X、右 Y、下 Z；不是把 USB 朝向直接当作前方。用户在每段采集前确认准备好，不能把未开始的采集描述成正在采集。
2. 初始静置到六轴姿态有效。分别围绕 **+X、+Y、+Z** 按右手方向慢转约 45–90°，暂停，再反向回到原姿态；各段独立标记，必要时重复。以安装旋转后的陀螺主轴正负确认动作，而非只看 Euler 数值；组合倾斜不等同于纯单轴动作。
3. 检查正反向磁矢量与六轴相对旋转的对应、分段残差和回到原姿态的重复性；对多个起始姿态复核。加速度是比力，静止时方向与 NED 重力相反，不能误作磁场轴符号依据。
4. 只有用户已知方向动作与离线对应一致，才形成安装核验结论；若磁矢量接近转轴导致某段不敏感，换起始姿态，不据该段单独判断。即使接受历史 FRD 定义，也仍需验证磁轴相对该定义的对应。

### 5.2 异常磁场与时效门控

- **数据质量**：先检查磁 valid/trim/config、溢出、有限数、总线错误及序号/时间戳；诊断帧不是测量。新观测按实际时间处理，不把同一 25 Hz 帧当成多份独立新观测，不插值补造丢失帧。
- **时效**：检查磁场读取完成年龄、非递增时间、重启/断线和磁—姿态时间配对；25 Hz 的正常周期约 40 ms，不能照搬 1 kHz IMU 的 1 ms 门限。具体新鲜度界限需结合轮询、转换/滤波延迟、真实间隔和运动速度验证；连续序号并不保证新鲜。
- **模长与方向**：使用固定候选参考模长、短时突变及方向/倾角一致性。模长正常仍可能是方向错误的干扰，不能只用模长门控；模型参考模长也不是绝对地磁真值。限制航向创新和校正速率，记录拒绝原因。
- **姿态可观性**：六轴姿态校准中/无效、四元数非有限或平方模异常、世界水平磁分量过小时不做磁航向修正。四元数投影不依赖 Euler pitch，不再用姿态大本身作为拒绝条件；运动中的重力方向质量仍要评估，不能用受线加速度污染的姿态强拉 yaw。
- **状态机与恢复**：异常立即停止磁修正、继续可用的六轴融合；持续若干合格样本/时长后才恢复，使用滞回避免抖动。坏场期间不学习新的场参考或 yaw 零点，恢复不突跳；磁失效不自动触发 IMU 重新校准。
- **回归**：注入尖峰、保持模长的方向干扰、连续坏场、饱和、重复/过期/乱序、丢帧和断线，检查拒绝计数、恢复时间和 yaw 连续性。各阈值先离线回放选择并冻结，再用独立数据核验，不用同一批数据调参并自验。

当前已实现质量、序号、时间/年龄、模长、四元数有效性、世界水平分量、磁倾角、航向创新、运动与恢复窗口门控，具体阈值见 [融合说明](bmm150-fusion.md)。尚无独立磁方向突跳门控；同模长/同倾角的缓慢方向干扰仍可能通过，启动干扰也可能被学成参考。上述要求不能当作所有干扰已经覆盖。

### 5.3 倾斜补偿与相对 yaw 验收

采用 body FRD → NED 四元数，将已修正且已安装旋转的磁矢量投影为 `m_world = R(q) m_frd`，比较世界水平磁方位与首次稳定窗口建立的固定参考。实现采用 `offset = atan2(-m_world.y, m_world.x)`、`innovation = wrap(offset - reference_offset)`，经增益和速度限制后**左乘世界 Z 旋转四元数**。它保持重力方向、不直接改陀螺零偏；具体公式和门限见 [融合说明](bmm150-fusion.md)。

完整 q 中已含当前航向估计，投影结果仅用于闭环固定参考误差，**不能冒充独立 yaw 测量或航向真值**。六轴静置初始化负责开机归零，晚建磁参考不重置当前 yaw。参考建立后遇坏场不重学参考，不因姿态大本身拒绝，但水平磁场不可观测、重力质量不可信或其他质量门控失败时仍停磁。四元数路径没有 Euler pitch 奇异点，不代表 Euler yaw 显示在 ±90° 附近也无奇异；竖直运动验收应检查四元数相对旋转和重力方向，不能只看 roll/yaw 数值。

1. 合成数据先验证坐标符号、±180° 跨越、多个 roll/pitch、±90°/跨竖直/倒置、q 与 −q 等价、世界 Z 修正不改变重力方向、磁偏角不影响相对航向；六轴重校准、磁参考未就绪及拒绝/恢复的状态必须有明确定义。
2. 实板先固定朝向、仅改变 roll/pitch，检查倾斜补偿后的相对航向；再正/反向转动并回到同一方向，检查符号、角度、重复性，并增加安全跨竖直与倒置复测，不能只看平放结果。
3. 同一原始记录离线比较未融合与候选融合，静置长时检查漂移斜率、波动及最大误差，转动检查相位/动态误差；门控拒绝率与恢复过程一起报告，不以过强平滑冒充抑漂。
4. 软件/回放验证后，当前构建默认启用实验性磁辅助；仍须复核 1 kHz 时序、原始输出/协议、USB 重连及静置/运动实测。软件通过与静态收流不能证明动态抑漂或绝对航向精度；完整磁 yaw 实板验收尚未完成。
