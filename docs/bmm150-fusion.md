# BMM150 相对磁航向辅助

## 默认配置与边界

新建 CMake 构建默认 ENABLE_EXPERIMENTAL_MAG_FUSION=ON，编译得到 FUSION_MAG_ENABLE=1。旧构建目录保留缓存，需显式设置 ON。使用 -DENABLE_EXPERIMENTAL_MAG_FUSION=OFF 可构建六轴对照固件；回放工具默认仍为六轴，需 --magnetic 开启磁辅助。

这是实验性相对 yaw 抑漂，不输出磁北或真北，也不保证所有环境下无漂移。软件回归和静态收流不能代替完整磁轴、倾斜补偿、真实转角与干扰实板验收。磁拒绝时继续六轴融合，不使正常六轴姿态失效。

## 数据与坐标

原始六轴和独立磁帧始终保留各自芯片寄存器轴。融合四元数表示机体 FRD 到世界 NED。IMU 沿用 ROTATION_PITCH_180；磁输入采用独立实验安装旋转，不能仅凭原理图证明方向。

    m_frd = diag(-1,-1,+1) * M * (m_chip - bias)

候选数值固化在 firmware/include/mag_calibration.h，来自 config/bmm150-calibration-candidate.json，测试锁定其 SHA256。JSON 是历史标定快照，不是运行时参数加载接口；其历史验收字段不表示当前已完成验收。原始磁帧只做厂商 trim 补偿，不输出内部硬软铁修正向量。

## 四元数磁向量与修正

磁融合不再读取 Euler roll/pitch/yaw。对已修正、已安装旋转的磁矢量，用当前归一化 FRD→NED 四元数投影到世界坐标：

    m_world = R(q) * m_frd
    horizontal = hypot(m_world.x, m_world.y)
    offset = atan2(-m_world.y, m_world.x)
    dip = atan2(m_world.z, horizontal)
    reference_offset = mean_wrap(offset)  # 仅首次稳定参考窗口
    innovation = wrap(offset - reference_offset)

等价地，若世界磁方位为 alpha，innovation 为 wrap(alpha_reference - alpha_current)，即绕世界下轴使当前水平磁向量转回固定参考方向的角度。这里完整 q 包含当前估计航向，因此世界磁方位是**闭环参考误差**，不是与姿态估计独立的绝对 yaw 测量；不能把它当作外部航向真值来评估自身精度。

    rate = clamp(0.15 * innovation, -1 °/s, +1 °/s)
    delta = rate * dt
    q_new = normalize([cos(delta/2), 0, 0, sin(delta/2)] ⊗ q)

公式中的角度运算使用弧度，比例增益为 0.15 s⁻¹。修正直接左乘到四元数，仅绕世界 Z（NED 向下）旋转，保持机体坐标中的重力方向不变，不直接修改陀螺零偏。非 Euler 奇异处 roll/pitch 不变；pitch 接近 ±90° 时 Euler roll/yaw 仍存在表示奇异性，不能用这些显示角的跳变判定四元数修正是否拉偏重力方向。

六轴静置初始化时 yaw 归零。首次磁参考即使晚建，也冻结当时相对世界坐标下的磁方位，不把当前 yaw 重置为零、不吞掉中间真实转角。25 Hz 新磁观测之间保持 innovation，并减去已施加修正，不用保持的 heading 目标阻尼真实转动。USB 断开继续融合；重连及暂时磁拒绝保留参考。融合重置或手动重新校准清参考并重新建立。

## 门控与恢复

- 磁质量低五位为 0x0F，error=0，向量有限。
- 新磁序号连续（支持 uint32 回绕），时间严格递增；相邻间隔及样本年龄不超过 100 ms。
- 修正后模长相对 47.88960059 µT 不超过 ±20%。
- 四元数有限、平方模在 [0.5, 1.5] 内，观测投影前局部归一化；世界水平磁分量/模长 ≥ 0.20。没有基于 Euler pitch 的倾角门限，大倾角本身不导致拒绝；世界水平磁分量不足仍属不可观测。
- 有参考时磁倾角偏差不超过 10°，航向 innovation 不超过 25°。
- IMU 姿态有效。运行时磁辅助与六轴 Mahony 加速度修正均要求加速度数据新鲜、无 SPI 错误且模长距 1 g ≤0.1 g，不再要求 200 ms 窗口内各轴加速度静稳；启动校准仍保留加速度和陀螺静置判据，磁等待阶段移动会重新校准。初建参考角速度模长不超过 5 °/s，有参考后不超过 90 °/s。
- 初建和拒绝后恢复均需至少 800 ms、20 个新磁样本；恢复窗口 offset/dip 相对首候选变化不超过 5°。
- 磁队列容量 8；溢出清磁积压、停磁并重新恢复，不伪造样本，不直接否定六轴姿态。

诊断 g_mag_fusion_diagnostics 提供提交、接受、拒绝、溢出、参考和辅助 tick 计数。reason_counts 是原因事件计数，不等同于逐帧拒绝样本数。

## 协议与上位机

IMU2 v3/type3 仍为 76 字节，CRC 与原字段不变，flags 新增：

| 位 | 含义 |
|---|---|
| 13 / 0x2000 | 正在磁辅助 |
| 14 / 0x4000 | 磁拒绝或等待恢复 |
| 15 / 0x8000 | 已有磁参考 |

合法磁位集合为 0、0x4000、0xC000、0xA000。关闭功能时为 0；旧固件全零仅表示未报告磁状态。GUI 显示磁状态，不将磁拒绝误作六轴无效。CSV 保存 flags，EuRoC 标准七列不变。另有约 25 Hz 的 IMU2 v1/type4/72 字节磁帧混流。

## 已知限制与实板验收

无独立方向突跳门控：同模长、同倾角缓慢方向干扰可能通过，启动干扰可能学成参考。最多 100 ms 迟到磁样本配当前姿态，无姿态历史插值。大倾角不再仅因 Euler pitch 而主动停磁；快速转动、线性加速度、重力质量不可信或磁观测异常仍可能停磁。四元数投影不自动消除磁噪声。运行时仅凭加速度模长不能识别所有线性加速度；即使模长接近 1 g，运动加速度仍可能拉偏 roll/pitch，继而影响倾斜补偿后的 yaw。这是允许运动辅助的实验性取舍，不代表飞行验收通过或保证 ±0.1° 精度。

软件回归覆盖 ±90°、跨竖直、倒置、多姿态、q 与 −q 等价、双向限速世界 Z 修正和重力方向保持；生产融合合成测试覆盖慢倾跨竖直及随后绕世界 Z 转动、约 ±30 °/s 倾转持续磁辅助、运动中拒绝后恢复、六轴重力反馈修正注入的陀螺误差，以及坏样本/模长异常仍拒绝加速度修正和启动静置要求保留。这些不证明全姿态实板性能。实板应继续核验实验磁轴、分姿态航向一致性、跨竖直和倒置运动、已知正负转角、长时静置漂移和干扰拒绝/恢复；竖直附近优先比较四元数相对旋转和重力方向，而非只比较 Euler yaw。不要放宽门限绕过失败。验证数据、烧录日志和运行报告仅留在忽略目录 logs/bmm150/，不提交。
