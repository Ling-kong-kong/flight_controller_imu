# 首版实施与验收记录

> **版本说明：第 1–9 节为此前版本的历史验收记录，不是当前接收时间方案的新验收。** 当前方案改为电脑读取完成时间统一，并全量导出 IMU、将未匹配图像字段留空；见第 10 节。历史记录中的仿射模型、有效对齐区间和曝光限制不应误读为当前仍在使用拟合。

验收日期：2026-11-18，Windows，本机实测。此记录区分代码测试、真实采集与尚未验证项目，不将属性返回值当成实测速率。

> **软件估算对齐，曝光同步误差未验证。** 本实现提供 H743 时间基准下的可复算软件估计，不保证图像曝光与 IMU 采样同一时刻，也不保证左右目曝光同步。未知固定传输延迟不能由本协议的单向观测消除，拟合残差不是曝光同步误差。

## 1. 实施与隔离

- 独立包、启动脚本、依赖、测试和说明文档全部放在仓库根目录 viewer 内；不动态导入固件、原有 tools 或其他目录的协议代码。
- 未修改固件、USB 描述符、CDC 协议、现有工具/协议文档/固件测试及构建烧录配置；未提交 Git。隔离复核：git diff --name-only 无已有跟踪文件修改，git status --short 仅出现未跟踪 viewer/。
- 虚拟环境、默认录制、默认导出、测试产物受 viewer/.gitignore 忽略。实测长会话通过 --output 显式选择 E 盘，属于数据保存位置，不是项目源码。
- 安装环境：Python 3.11.13；PySide6 6.12.0；OpenCV 4.14.0.94；NumPy 2.4.6；pyserial 3.5；psutil 7.2.2。
- 包含 GUI、无界面联合录制、设备发现、完整会话时钟重算、原始数据完整性审计及 EuRoC 导出。CLI 使用 Recorder；GUI 使用 LiveConnection 维持实时设备连接，开始录制时挂接独立 Recorder 写盘端，停止保存不关闭设备。两条路径复用相同的协议、校验和保存实现。

## 11. 时间轴滚轮误锁纵轴修复

2026-11-19：根据角速度图波形截顶的截图排查，仅修改 viewer 的波形滚轮处理、回归测试和说明，不修改固件、CDC、采集、原始数据、单位换算、时间映射或导出。

### 复现与根因

- 通过 Qt offscreen 真实 viewport 滚轮事件，缩放角速度图时间轴后回到实时，再从历史采集接口加入 ±1000 原始整数（±61.03515625 °/s）数据。
- 修复前：曲线数据已含上述峰值，但纵轴仍固定在约 −0.299～6.403 °/s；自动缩放状态变为关闭。两张图的普通滚轮均可触发，不是角速度独有的换算问题。
- 根因：`WaveViewBox.wheelEvent()` 使用 `scaleBy((factor, 1))`；PyQtGraph 将两个显式倍率都视为设置对应轴，即使纵轴倍率为 1，也会关闭纵轴自动范围。回到实时只恢复时间跟随，不恢复纵轴自动，因此手动时间缩放的副作用可延续到实时预览。
- 修复：普通滚轮使用 `scaleBy(x=factor)`，纵轴滚轮使用 `scaleBy(y=factor)`，只操作目标轴。主动调整纵轴仍保留手动范围；点击“纵轴自动”恢复自动适配，不以自动恢复覆盖用户的幅值选择。

### 验证与边界

- 先加入回归测试并验证失败（3 个失败断言），再修复；相同测试修复后通过。新增 2 项覆盖新增角速度峰值的完整显示、三轴名义换算保持、两图时间滚轮保留纵轴自动／手动模式，以及手动纵轴范围不被时间滚轮改变。
- `compileall` 通过；完整 `unittest discover -s tests -v` **73 项通过，29.491 秒**。日志：`test-results/gyro-axis-before.txt`、`test-results/gyro-axis-after.txt`、`test-results/gyro-axis-regression.txt`。
